# StreamSafeArea

一个 macOS 本地悬浮提示工具，用来在共享屏幕上标记直播时右下角人物画中画（PIP）可能遮挡的区域，也支持直接显示摄像头实时预览。

## 当前功能

- 桌面悬浮矩形提示框
- 支持两种模式：
  - **线框模式**：只显示边框/淡填充
  - **视频模式**：显示摄像头实时预览
- 可拖动位置
- 可直接缩放窗口大小
- 可调边框透明度
- 可调填充透明度
- 可调边框粗细
- 可调视频透明度
- 可调圆角
- 可切换点击穿透
- 可切换镜像视频
- 可设置视频模式下是否保留边框
- 可一键吸附到当前屏幕右下角
- 自动记住上次位置和尺寸
- 提供简单控制面板
- 提供顶部状态栏图标（SSA）

## 使用说明

- 启动后默认显示线框模式，并自动打开控制面板。
- 可以直接拖动窗口移动位置。
- 可以直接拖拽窗口边缘或角落调整大小。
- 可以在控制面板里切换到“视频模式”。
- 顶部状态栏会出现 `SSA` 图标，可直接切线框/视频模式、隐藏/显示悬浮窗。
- 第一次切到视频模式时，macOS 可能会请求摄像头权限。

控制面板支持：

- 在线框 / 视频模式之间切换
- 修改宽度/高度
- 调整边框透明度
- 调整线框填充透明度
- 调整边框粗细
- 调整视频透明度
- 调整圆角
- 打开/关闭点击穿透
- 打开/关闭镜像视频
- 设置视频模式保留边框
- 一键吸附右下角
- 隐藏/显示提示框

## 当前建议用法

- **日常直播**：优先用线框模式，干扰更低。
- **开播前对位置**：切到视频模式，更直观看人物画面会遮住哪里。
- **直播中临时避让内容**：保留视频模式，手动拖到不挡内容的位置。

## 已知限制（当前版本）

- 目前默认只做一个悬浮框/视频窗
- 还没有全局快捷键
- 还没有多显示器显式切换 UI
- 还没有锁定宽高比
- 还没有 menubar-only 模式
- 还没有正式签名与发布打包
