# StreamSafeArea

一个 macOS 本地悬浮提示工具，用来在共享屏幕上标记直播时右下角人物画中画可能遮挡的区域，也支持直接显示摄像头实时预览。

## 当前功能

- 线框模式 / 视频模式
- 动态列出当前摄像头实际可用分辨率
- 点击穿透开关
- 锁定位置与尺寸开关
- 可拖动、缩放、吸附右下角
- 可把悬浮窗移动到鼠标所在屏幕
- 顶部状态栏图标 `SSA`

## 运行

```bash
open /Users/jkw/Documents/OfficalProjects/StreamSafeArea/dist/StreamSafeArea.app
```

## 说明

- 点击穿透现在只负责“鼠标穿透”，不应该再改位置。
- 锁定位置与尺寸用于防止误拖动、误缩放。
- 全屏覆盖已可用；如果跨屏拖动不顺，优先用“到鼠标屏幕”。
