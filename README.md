# StreamSafeArea

一个 macOS 本地悬浮提示工具，用来在共享屏幕上标记直播时右下角人物画中画（PIP）可能遮挡的区域，也支持直接显示摄像头实时预览。

## 当前功能

- 桌面悬浮矩形提示框
- 支持两种模式：
  - **线框模式**：只显示边框/淡填充
  - **视频模式**：显示摄像头实时预览
- 可选择摄像头分辨率：自动 / 1280×720 / 1920×1080 / 3840×2160
- 可拖动位置
- 可直接缩放窗口大小
- 可调边框透明度
- 可调填充透明度
- 可调边框粗细
- 可调视频透明度
- 可调圆角
- 可切换点击穿透
- 可切换镜像视频
- 可设置视频模式下是否保留边框
- 可一键吸附到当前屏幕右下角
- 可一键移动到鼠标所在屏幕
- 自动记住上次位置和尺寸
- 提供简单控制面板
- 提供顶部状态栏图标（SSA）

## 使用说明

- 启动后默认显示线框模式，并自动打开控制面板。
- 可以在控制面板里切换到“视频模式”。
- 可以在控制面板里切换摄像头分辨率。
- 顶部状态栏会出现 `SSA` 图标，可直接切线框/视频模式、隐藏/显示悬浮窗，也能把悬浮窗一键送到鼠标所在屏幕。
- 第一次切到视频模式时，macOS 可能会请求摄像头权限。

## 说明

- 我们已经尽量把窗口行为往“全屏辅助浮层”方向推了，但 macOS 对某些全屏 Space 仍可能有限制。
- 如果遇到拖不过去的情况，优先使用 **到鼠标屏幕**。
